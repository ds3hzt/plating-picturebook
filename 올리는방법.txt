도금 그림백과 — GitHub Pages 로 웹 링크 만들기 (프로그램 설치 필요 없음, 브라우저만)
이 "배포" 폴더 전체가 웹사이트입니다. index.html 이 첫 화면입니다.

1) 저장소 만들기
   - github.com 로그인(계정 없으면 무료 가입)
   - 오른쪽 위 + > New repository
   - Repository name: plating-picturebook  (영문 소문자·하이픈 권장, 주소에 들어감)
   - Public 선택(무료 Pages 는 Public 필요)  ← 주소를 아는 누구나 볼 수 있음
   - "Add a README file" 은 체크하지 않아도 됨 > Create repository

2) 파일 올리기
   - 새 저장소 화면의 "uploading an existing file" 링크 클릭
     (또는 Add file > Upload files)
   - 탐색기에서 "배포" 폴더를 열고, 안의 파일·폴더를 전부 선택
     (index.html, suso.html, terms.js, g 폴더)  → 브라우저 창으로 끌어다 놓기
     ※ "배포" 폴더 자체가 아니라 그 "안의 내용"을 올려야 합니다. 올림 후 목록에 index.html 이 바로 보여야 정상.
   - 아래 Commit changes 클릭
   (올리기 전에 g 폴더 안 p0.js ~ p7.js, lib.js 까지 12개 파일이 보이는지 확인)

3) Pages 켜기
   - 저장소 상단 Settings > 왼쪽 Pages
   - Build and deployment > Source: Deploy from a branch
   - Branch: main, 폴더: / (root) > Save
   - 1~3분 뒤 같은 화면 위쪽에 주소가 표시됨:
       https://<GitHub계정이름>.github.io/plating-picturebook/
     이 주소가 외부에서 열리는 링크입니다.

내용을 고친 뒤 다시 올릴 때
   - 저장소에서 Add file > Upload files 로 같은 이름 파일을 덮어쓰기(Commit) → 1~3분 뒤 반영

주의
   - 올린 자료는 링크를 아는 누구나(검색엔진 포함) 볼 수 있습니다.
   - 파일 이름·g 폴더 구조를 바꾸면 화면이 비게 됩니다.
   - 주소에 대소문자 구분이 있을 수 있으니 안내된 그대로 사용하세요.
